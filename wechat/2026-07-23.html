当技术越过红线

DARPA的AI战机试飞与基因治疗致死案，共同敲响技术伦理警钟；而开源AI权重之争则牵动全球政策神经。

━ 1 ━ 自主武器AI已飞向战场

DARPA与美国空军成功试飞AI控制F-16，社区评论混合了科幻调侃与安全性质疑。自主武器系统距离实战更近一步，但人类临时接手的能力如何保障？这不仅是技术问题，更是伦理红线。

▸ DARPA与美国空军成功试飞AI控制F-16

DARPA和美国空军成功完成了由人工智能完全控制的F-16战斗机飞行测试，这是自主空战技术从模拟走向现实的关键一步。 此次测试标志着人工智能在复杂、高速的军事航空环境中取得了重大突破，可能彻底改变未来空战模式，加速无人作战平台的部署。 测试飞机配备了特殊接口，允许飞行员通过开关在人类操控和AI操控之间切换，保证了人机协作实验的安全性。AI算法此前已在模拟器中与人类飞行员进行过数千次格斗训练。

━ 2 ━ 基因治疗的代价：80万美元换不来安全

一项付费超过80万美元的基因编辑治疗导致患者死亡，社区强烈批评医生使用AAV载体直接注入大脑的风险预估不足。AAV免疫反应在已获批疗法中已有记录，脑部注射风险更高。伦理问题不容回避。

▸ 付费超过80万美元的基因编辑治疗导致女儿死亡

一对夫妇为患有发育障碍的女儿支付超过80万美元接受实验性基因编辑疗法，但该疗法导致女儿死亡，这一悲剧案例此前从未被公开报道。 这起事件凸显了未经充分验证的实验性基因疗法对患者带来的巨大风险，尤其在涉及儿童和脑部治疗时，伦理审查和安全性评估的重要性更为突出。 该疗法使用腺相关病毒（AAV）载体将基因导入大脑，但AAV载体已知具有免疫原性，可能导致严重不良反应。动物实验中也出现了类似副作用，但医生可能低估了风险。

▸ 创始人吁美勿禁中国开源权重AI

▸ 反开源AI的论据站不住脚

━ 5 ━ Python部署新利器：pip --only-deps

Pip 26.2引入--only-deps选项，专为解决部署中依赖碎片化难题。在容器化与微服务时代，精准控制依赖版本至关重要。这一更新将简化CI/CD流程，值得立即试用。

▸ Pip 26.2 引入 --only-deps 解决部署难题

Pip 26.2 版本新增了 --only-deps 全局标志，允许用户仅安装项目的依赖项，而无需安装项目本身。该功能通过 PR #13895 实现，解决了长期以来的部署痛点。 这一功能解决了 16 年来 Python 应用部署中的常见 hack，简化了 Docker 镜像构建等场景下的依赖安装流程。它将提升 Python 包管理的一致性和效率，减少临时工作脚本的维护成本。 新标志可与 pip install 配合使用，例如 pip install --only-deps . 会安装 pyproject.toml 中声明的所有依赖，但跳过包本身的安装。该功能支持可选依赖组（如 extras）。
